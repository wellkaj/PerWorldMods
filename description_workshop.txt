[h1]Per-World Mods[/h1]
[h3][i]Different worlds, different mods — no more switching mods back and forth. / 不同世界用不同模组，不用再来回切换。[/i][/h3]

[b]One mod list per world.[/b] Calamity in world A, vanilla in world B, building mods in world C — every world remembers its own set, and the right set is loaded when you open it.
[b]每个世界一份模组清单。[/b] 想在 A 世界玩灾厄、B 世界玩原版、C 世界玩建筑？每个世界自己记住要用哪些模组，打开哪个世界就自动加载哪一套。

[h2]What it solves / 它解决什么[/h2]
[list]
[*][b]Different mods per world.[/b] World A and world B can run completely different mod sets, and neither affects the other.
[b]不同世界，不同模组。[/b] A 世界和 B 世界可以用完全不同的模组组合，互不影响。
[*][b]No Workshop shuffling.[/b] A mod only needs to be downloaded once; after that the sets are assembled per world. No subscribing and unsubscribing just to switch worlds, and no toggling mods by hand every time.
[b]不用在创意工坊里来回切换。[/b] 模组只要下载一次，之后按世界自动组合；不用为了换世界反复订阅 / 取消订阅，也不用一遍遍手动开关。
[*][b]No restart.[/b] A world's mod set is swapped in-process, with seed, name, size, difficulty and world evil all preserved.
[b]不用重启游戏。[/b] 切换模组在进程内完成，种子、名字、大小、难度、世界邪恶全部保留。
[*][b]Remembers which character belongs to which world.[/b] Mark a character as a world's owner, then a single click switches to that world's mods and enters it — no prompt.
[b]记住角色对应的世界和模组。[/b] 把角色标记为某个世界的主人，用这个角色点一下就自动切到该世界的模组并直接进世界，不再弹窗。
[/list]

[h2]Features / 特性[/h2]
[list]
[*]Three-way prompt when the loaded mods don't match: switch & enter / enter anyway / cancel. In multiplayer the server decides.
模组对不上时三选一：「切换并进入」/「直接进入」/「取消」。多人游戏以服务器为准。
[*]Dependency-aware selection: ticking a mod ticks its requirements, unticking removes its dependents — same rules as Manage Mods.
依赖联动：勾选自动带上前置，取消自动取消依赖它的模组，规则和「管理模组」一致。
[*]Readable world-list status: missing / pending / vanilla / OK, so you know at a glance what to do.
世界列表状态一目了然：缺失 / 待生效 / 原版 / 正常。
[*]Built-in manual: a 使用说明 button opens an in-game help page.
内置使用说明：点「使用说明」按钮直接看游戏内帮助页。
[/list]

[h2]Good to know / 注意[/h2]
[list]
[*]Mods must already be downloaded. The mod never downloads anything and never auto-adds mods to a world.
模组必须已经下载好。它不会下载任何东西，也不会自动往世界里加模组。
[*]It never hard-blocks world entry: if mods are missing you can still choose to enter anyway.
不会硬拦着进世界：缺模组时你随时可以选择照样进入。
[*]Switching needs one reload; the first screen after it is the world-creation menu. Character-tagged worlds and "switch & enter" handle that for you.
切换模组需要一次重载，重载后第一屏是世界创建界面；角色世界和「切换并进入」会自动帮你进世界。
[/list]
